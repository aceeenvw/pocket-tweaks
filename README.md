# ⊹ Pocket Tweaks ⊹

Compact UI and chat workflow tweaks for SillyTavern. Every feature can be toggled in **Extensions → Pocket Tweaks**.

## Features

- **Prompt row actions** — Duplicate a custom prompt below the original and edit the disabled copy, or delete it from this preset after confirmation. On mobile, open **⋯** for these actions and **Remove from this order**. Toggle under **Editors**.

- **Optional editor integrations** — Choose a persona for a new solo chat with Quick Persona Pro. With a compatible Code Mirror Pro, search alternate greetings and open the matching passage.

- **Replacement preview** — Review changed character text and greetings before replacing a card with a local PNG or JSON file.

- **Alternate Greetings** — Choose an opening when starting a character chat, swap it with First Message in the editor, or name, duplicate, and reorder alternates. Names travel with JSON and PNG cards.

- **Adaptive Floating Dock** — Draggable, resizable floating window combining **OOC Inject** and **Message Actions** (shows either one, both with an adjustable split, or hides when disabled; supports shy icon mode).
- **OOC Inject** — Persistent per-chat OOC instruction with configurable depth and live status.
- **Message Actions** — Quick access to the last two messages, distinct copy and duplicate controls, and item previews in chat and message delete confirmations.
- **Jump-to-Bottom Arrow** — Auto-appearing corner button when scrolled up in chat.
- **Character Avatar Crop** — Lossless PNG crop dialog (`Free`, `1:1`, `2:3`, `3:4`, `4:5`, `5:4`, `4:3`) on upload and in-place re-cropping for existing avatars.
- **Prompt Editor Maximize** — Adds an expand button next to the **Prompt** field in Prompt Manager.
